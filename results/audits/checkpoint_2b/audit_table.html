Definitions and limitations

[A] UNSW key fields: dur, spkts, dpkts, sbytes, dbytes, rate.

[B] Exact duplicates: repeated occurrences across each dataset's loaded files, comparing all columns except id for UNSW; all columns for CICIDS2017 and TON_IoT. Two independent 64-bit row fingerprints; collisions theoretically possible.

[C] Candidate near-duplicates use a 20,000-row UNSW training sample (seed 42). Same protocol, service, state and directional packets; duration rounded to 0.01 s, total bytes to 100; at least two different full network patterns. Count is sample rows in candidate groups.

[D] Repeated entities unavailable: no host/user/device identifier in prepared UNSW CSVs (id is a row number).

[E] Primary dataset time range unavailable: no timestamp column in loaded UNSW CSV files.

[F] External time ranges not required: dataset-boundary split, not time split.
